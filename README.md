# DepthWeaver — website

Static marketing / support site for **DepthWeaver**, a native iPhone and Mac app that turns LiDAR scans, on-device AI depth, 3D models and Object Capture scans into Magic Eye autostereograms.

**Live:** https://glandais.github.io/DepthWeaver/ (GitHub Pages, served from this repo)

## Pages

| Path | Content |
| --- | --- |
| [`index.html`](index.html) | Home — features, what's new, App Store call-to-action |
| [`support/`](support/index.html) | Quick start, viewing tips, FAQ, known limitations, bug reporting |
| [`privacy/`](privacy/index.html) | Privacy policy (no data collected) |

Plain HTML + one stylesheet (`assets/style.css`), no build step. Every page carries the Smart App Banner meta tag (`apple-itunes-app`, app ID `6764146054`).
